## Looking things up on the web

Jizza and your specialists can search the web and read pages. Ask about anything current ("what changed in the new GST rates?") or paste a link and ask about it. The pages a reply drew on show as links under it, so you can check them.

Searches leave Jizza, so it searches for the general question and keeps your personal details out of the search.

Each agent has a switch for this: open the agent in [Agents](/agents), then **Tools**, and tick or untick **Search the web and read pages**. It's on for every agent to begin with.

## Sending files

Press **+** and choose **Add files or photos**, drag files onto the message box, or paste a copied file or screenshot into it.

- **Text, Markdown and CSV** files go into the message as they are.
- **Word (.docx), Excel (.xlsx) and PowerPoint (.pptx)** files are read on the server. Each sheet of a workbook and each slide of a deck is labelled, so you can ask about one of them.
- **PDFs and photos** upload, and Jizza reads or looks at them.
- Older Office files (.doc, .xls, .ppt) can't be read: save them in the newer format first.

A very large spreadsheet is cut to fit the message, so ask about one sheet at a time if it's big.

## Asking a specialist with @

Start a message with **@** and pick a specialist, for example `@Kai how are my investments doing?`. That specialist answers it themselves, with their own memory and tools, and their name and logo show on the reply. Without an @, Jizza decides who should help.

## Shortcuts

Type **/** in the message box to see the shortcuts for where you are. Wherever you are, you have:

| Shortcut | What it does |
| --- | --- |
| /run | Runs a saved workflow now, with no AI and no tokens |
| /thread | Turns threads on for this chat and starts a thread on a topic |
| /remember | Starts a sentence for Jizza to keep in memory |
| /model | Uses the deeper model for your next message only; type it again to switch back. To pick a model for the whole chat, use the model button under the message box ([Pick the AI model for a chat](/help/ai-models)) |
| /new | Starts a new conversation |
| /help | Lists the shortcuts here |

## Rating replies

Under each reply there's a thumbs up and a thumbs down. Tap one and, if you like, say why. Tap it again to take it back.

In a thread, what you say is added to the thread's guide under **How to work here**, so its lead does better next time. Every rating also shows on the [Activity › Usage](/usage) page under **Reply quality**: each agent's thumbs for the last 30 days, and the latest replies you rated with your reasons.
